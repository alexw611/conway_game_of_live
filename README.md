🎮 Conway's Game of Life
Eine interaktive Implementierung von John Conway's legendärem "Game of Life" - einem zellulären Automaten, der mit nur drei einfachen Regeln komplexe Muster und Verhaltensweisen erzeugt.

📖 Über das Spiel
Vor über 50 Jahren entwickelte der Mathematiker John Conway ein Spiel, das unsere Sicht auf die Welt verändern sollte. Es besteht nur aus schwarzen und gelben Quadraten, aber es erzeugt faszinierende Welten mit Objekten, die sich fortbewegen, interagieren oder sogar "beschießen" - obwohl das alles überhaupt nicht einprogrammiert wurde!
🎯 Die drei Regeln

Überleben: Eine lebende Zelle mit 2 oder 3 lebenden Nachbarn überlebt
Geburt: Eine tote Zelle mit genau 3 lebenden Nachbarn wird lebendig
Tod: Alle anderen Zellen sterben oder bleiben tot
